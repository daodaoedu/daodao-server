# PRD｜DaoDao B2B 學習社群與共同挑戰

## 產品定位

> 「讓老師透過島島輔助學員與課程推展，達到一般課程沒辦法完成的互動與資料分析。」

DaoDao 不是單純的打卡工具，而是**讓學習歷程被看見的平台**。  
學員累積打卡 → 歷程可視化 → 成長地圖與報表 → 被老師、社群、自己看見。

---

## 目標用戶

| 角色 | 描述 |
|------|------|
| 老師 / 課程主理人 | 帶學員養成習慣、追蹤學習計畫 |
| KOL / 讀書會主持人 | 帶社群共同完成某個目標 |
| 一般用戶（任何人） | 揪朋友一起備考、運動、讀書 |
| DaoDao 官方 | 建立熱門時效性挑戰活動 |

## 三個功能層次

### 層次 1：主題實踐（個人）
- 學員自建打卡目標（`practices`）
- 每日打卡（`practice_checkins`）
- 個人成長地圖、連續天數

### 層次 2：學習計畫（師生）
- 老師建立學習計畫（`project`）
- 任務拆解（`task`）、里程碑（`milestone`）、成果（`outcome`）
- 搭配學習馬拉松（`marathon`）做限時衝刺
- 老師後台看班級進度分析

### 層次 3：共同挑戰（社群）← Phase 1 重點
- 任何人都可以發起，有明確時效性
- 學員「加入」挑戰（非複製），共同打卡同一主題
- 打卡牆公開可見，可選排名機制
- 典型場景：
  - 英檢／日檢備考（考試日為終點）
  - 熱門書籍讀書會（限期讀完）
  - 運動目標（高爾夫最低桿數、馬拉松配速）
  - 課程認證（Claude AI 課程）

## Phase 1 範圍（MVP）

**由 DaoDao 官方建立幾個有時效性的熱門共同挑戰，開放學員加入。**

### 學員可以做的事
- 瀏覽、搜尋公開挑戰
- 加入挑戰
- 每日打卡（含文字、照片）
- 看自己的打卡進度與連續天數
- 看其他成員的打卡牆
- 看排名榜（可選）
- 分享自己的成長記錄

### DaoDao 內部管理（admin-ui）
- 建立官方挑戰（標題、描述、主題、開始/結束日）
- 設定公開或封閉
- 查看挑戰數據（加入人數、打卡率、活躍度）

### Phase 1 不做
- 付費報名 / 獎金池機制
- 老師/KOL 自行建立挑戰（Phase 2）
- 發起人後台 dashboard（Phase 2）

---

## Phase 2 範圍

- 開放任何人建立共同挑戰
- 發起人後台（`/dashboard`）：成員管理、打卡分析、公告
- 封閉挑戰的邀請機制
- 付費競技型挑戰（報名費 → 排名獎金池）

## Phase 3 範圍

- 層次 2 學習計畫整合（老師帶學員的 project + milestone 分析）
- 跨挑戰的學員成長地圖
- KOL 認證計畫

## 商業模式

- **推廣期**：全免費，無 quota 限制
- **未來**：競技型挑戰收報名費，DaoDao 抽手續費（無導師人事成本）

### 一般人為什麼願意付費？

參加是一回事，付費是另一回事。免費就能做的事（自己設目標、找朋友口頭約定）不需要買單；一般人願意付費，通常是為了買下面幾種心理機制，而不是「功能」本身：

| 動機 | 說明 |
|------|------|
| 承諾機制（Commitment Device） | 付費本身是一種「逼自己不能放棄」的工具，沉沒成本讓人更難半途而廢（同類機制如 Stickk.com） |
| 賭注 / 獎金池 | 一群人各付一點小錢，完成者平分獎金，未完成者的錢進入獎金池，帶來臨場感與動力 |
| 有結構的挑戰設計 | 自己想「我要每天讀書」容易放棄；買的是「幫我把目標拆成有節奏的每日任務」這件事 |
| 社群感與被看見 | 免費打卡沒人看；花錢加入的挑戰裡有一群人同步在做、互相加油，買的其實是「歸屬感」和「不孤單」 |

一句話：一般人付費買的不是挑戰本身，而是**「一個讓自己沒有藉口放棄的機制」**。

### 對應的付費層設計（未來）

```
免費層（Phase 1，現在做）
  瀏覽、加入、打卡、看排名
  → 先把「社群感」和「被看見」做好，這是黏著度的根本

付費層（未來）
  ├── 報名費 → 獎金池（競技型）
  │   e.g., 100 人各付 100 元，打卡率前 10 名平分獎金
  │   → 賣的是「賭一把逼自己」
  │
  ├── 精緻挑戰（策展費）
  │   DaoDao 官方或 KOL 設計的高品質挑戰，
  │   有明確每日任務與進度節奏設計
  │   → 賣的是「有人幫我規劃好了」
  │
  └── 保證金退還制
      e.g., 報名付 500 元，完成 80% 打卡全額退還，
      未完成部分進入獎金池或捐公益
      → 賣的不是「買挑戰」，是「逼自己完成」
```

這跟陪伴計畫的商業邏輯正好互補：共同挑戰用「金錢 + 社群壓力」對抗惰性，陪伴計畫用「關係 + 被看見」維持動機。兩者不衝突，是同一個底層打卡引擎上的兩種不同動機設計。
