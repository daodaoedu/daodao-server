# DaoDao Server - 服務層分析文件

## 總覽

本文件詳細分析 `/src/services` 目錄下的所有服務模組，確認業務邏輯的正確性與完整性。

## 服務架構

### 資料庫服務 (Database Services)
**位置**: `src/services/database/`

#### Prisma 服務 (`prisma.service.ts`)
- **功能**: PostgreSQL 資料庫 ORM 管理
- **主要特性**:
  - 支援分散式交易
  - 連線池管理
  - 健康檢查機制
  - 優雅關閉處理

#### Redis 服務 (`redis.service.ts`)
- **功能**: 快取與 Session 管理
- **主要特性**:
  - 連線重試機制
  - 錯誤處理
  - 效能監控

#### MongoDB 服務 (`mongo.service.ts`)
- **功能**: 文件導向資料存儲
- **主要特性**:
  - Mongoose ODM 整合
  - 連線狀態管理

### 認證服務 (Authentication Services)
**位置**: `src/services/auth/`

#### OAuth 服務 (`oauth.service.ts`)
- **功能**: Google OAuth 2.0 認證整合
- **業務邏輯**:
  - 新用戶創建臨時用戶記錄
  - 已註冊用戶返回正式用戶資料
  - Session 序列化/反序列化
- **安全特性**:
  - 環境變數驗證
  - 用戶狀態區分 (temp/user)
  - 錯誤處理機制

#### 認證服務 (`auth.service.ts`)
- **功能**: 用戶認證與授權核心邏輯
- **業務邏輯**:
  - 臨時用戶建立與管理
  - 正式用戶查詢與驗證
  - 電子郵件查詢功能

#### 權限服務 (`permission.service.ts`)
- **功能**: 角色權限管理
- **業務邏輯**:
  - 角色權限檢查
  - 功能存取控制

### 核心業務服務 (Core Business Services)

#### 用戶服務 (`user.service.ts`)
**主要功能**:
- 用戶生命週期管理 (CRUD)
- 分頁查詢與篩選
- 完整度評分系統
- 資料格式轉換

**業務邏輯**:
1. **用戶查詢**:
   - 支援教育階段、角色、地區篩選
   - 按完整度排序
   - 分頁處理
   
2. **用戶註冊**:
   - 臨時用戶轉正式用戶
   - 資料驗證與完整性檢查
   - 關聯資料建立 (基本資訊、聯絡方式、職位)
   
3. **完整度計算**:
   - 自我介紹長度評分
   - 分享內容評分
   - 標籤、聯絡方式、地區、職位加分

#### 專案服務 (`project.service.ts`)
**主要功能**:
- 學習專案管理
- 里程碑與任務管理
- 權限控制
- 統計分析

**業務邏輯**:
1. **專案建立**:
   - 角色權限驗證 (角色2無法新增、角色3限制3個專案)
   - 日期邏輯驗證
   - 里程碑與任務關聯建立
   
2. **存取控制**:
   - 公開專案所有人可見
   - 私人專案僅創建者可見
   - 修改權限僅限創建者

#### 資源服務 (`resource.service.ts`)
**主要功能**:
- 學習資源管理
- 標籤系統整合
- 評價統計
- 多維度篩選

**業務邏輯**:
1. **資源查詢**:
   - 標籤篩選預處理
   - 多維度條件查詢 (類型、費用、難度、分類)
   - 評價統計計算
   
2. **權限管理**:
   - 創建者可修改/刪除
   - 軟刪除機制
   - 資料完整性驗證

#### 標籤服務 (`tag.service.ts`)
**主要功能**:
- 標籤生命週期管理
- 實體標籤關聯
- 使用統計分析
- 清理機制

**業務邏輯**:
1. **標籤管理**:
   - 避免重複建立
   - 自動關聯實體
   - 批量操作支援
   
2. **統計功能**:
   - 熱門標籤排行
   - 使用頻率統計
   - 未使用標籤清理

### 輔助服務 (Utility Services)

#### 轉換服務 (`transform.service.ts`)
**功能**: API 與資料庫資料格式轉換

#### JWT 服務 (`jwt.service.ts`)
**功能**: JWT Token 生成與驗證

#### 電子郵件服務 (`email/`)
**功能**: 郵件發送與模板管理
