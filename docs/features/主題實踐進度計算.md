# 主題實踐進度計算

Main Feature: 主題實踐
Status: Done

## **Purpose/Problem**

為「主題實踐」功能設計一套彈性的進度計算系統，支援使用者設定：

- 實踐期間（7-30 天）
- 每週實踐節奏（如：每週 3-5 天）
- 每日具體目標（如：每日讀 5 頁、練習 30 分鐘）

## 功能概述

### 核心價值

- **彈性目標設定**：同時支援頻率目標（多少天）和量化目標（多少頁/分鐘）
- **精確進度追蹤**：根據實際完成量計算進度百分比
- **正向激勵**：以最低目標為 100% 基準，超標時可突破 100%

### 設計理念

**以最低目標為 100% 基準**，當使用者達成最低目標即顯示 100%，超過最低目標時進度可超過 100%，最高可達理想目標的百分比（通常 150-170%）。

## 使用者故事

**身為一位學習者，我希望能夠：**

- 設定符合我生活節奏的實踐期間（如：10 天挑戰）
- 設定彈性的每週頻率（如：每週讀書 3-5 天）
- 設定具體的每日目標（如：每日讀 5 頁或練習 30 分鐘）
- 清楚知道我的總目標是多少（如：需要讀完 25-40 頁）
- 看到我的實際進度百分比
- 當達成最低目標時獲得「100% 達標」的成就感
- 當超過最低目標時看到進度突破 100%

### 計算週期

由於實踐期間可能不是完整的週數，需要分別計算：

**A. 完整週數計算**

```
完整週數 = floor(實踐期間 / 7)
```

**B. 剩餘天數計算**

```
剩餘天數 = 實踐期間 % 7
```

**範例**：

- 10 天實踐期：1 完整週 + 3 剩餘天
- 15 天實踐期：2 完整週 + 1 剩餘天
- 21 天實踐期：3 完整週 + 0 剩餘天

---

### 目標天數計算

**A. 完整週的目標天數**

```
完整週最低目標總天數 = 最低目標 × 完整週數
完整週理想目標總天數 = 理想目標 × 完整週數
```

**B. 剩餘天數的目標天數（按比例計算）**

```
剩餘天數最低目標 = ceiling(最低目標 × 剩餘天數 / 7)
剩餘天數理想目標 = ceiling(理想目標 × 剩餘天數 / 7)
```

**C. 總目標量計算 ⭐**

```
總最低目標 = 每日目標 × 總最低天數
總理想目標 = 每日目標 × 總理想天數
```

### 計算範例

**範例 1：10 天實踐期，每週 3-5 天，每日 5 頁**

### Step 1: 計算週期

```
實踐期間 = 10 天
完整週數 = floor(10 / 7) = 1 週
剩餘天數 = 10 % 7 = 3 天
```

### Step 2: 計算實踐天數目標

**最低天數目標：**

```
完整週最低天數 = 3 天/週 × 1 週 = 3 天
剩餘天數最低天數 = ceiling(3 × 3 / 7) = ceiling(1.286) = 2 天
總最低天數 = 3 + 2 = 5 天
```

**理想天數目標：**

```
完整週理想天數 = 5 天/週 × 1 週 = 5 天
剩餘天數理想天數 = ceiling(5 × 3 / 7) = ceiling(2.143) = 3 天
總理想天數 = 5 + 3 = 8 天
```

### Step 3: 計算總目標量

```
總最低目標 = 5 頁/天 × 5 天 = 25 頁
總理想目標 = 5 頁/天 × 8 天 = 40 頁
```

### Step 4: 計算理想目標百分比

```
理想目標百分比 = (總理想目標 / 總最低目標) × 100%
               = (40 / 25) × 100%
               = 160%
```

**總結**：

- ✅ 最低目標：**25 頁**（100%）
- ✅ 理想目標：**40 頁**（160%）

**範例 2：15 天實踐期，每週 4-6 天，每日 30 分鐘**

### Step 1: 計算週期

```
完整週數 = floor(15 / 7) = 2 週
剩餘天數 = 15 % 7 = 1 天
```

### Step 2: 計算實踐天數目標

**最低天數：**

```
完整週: 4 天/週 × 2 週 = 8 天
剩餘天: ceiling(4 × 1 / 7) = ceiling(0.571) = 1 天
總計: 8 + 1 = 9 天
```

**理想天數：**

```
完整週: 6 天/週 × 2 週 = 12 天
剩餘天: ceiling(6 × 1 / 7) = ceiling(0.857) = 1 天
總計: 12 + 1 = 13 天
```

### Step 3: 計算總目標量

```
總最低目標 = 30 分鐘/天 × 9 天 = 270 分鐘
總理想目標 = 30 分鐘/天 × 13 天 = 390 分鐘
理想目標百分比 = (390 / 270) × 100% = 144%
```

### 進度百分比計算

- **用戶打卡後計算進度**
- **以總最低目標天數為 100% 基準**
    
    **特性**：
    
    - 當實際完成量 = 總最低目標時，進度 = 100%（達標）
    - 當實際完成量 > 總最低目標時，進度 > 100%（超標）
    - 進度百分比可以超過 100%，最高可達理想目標的百分比
        
        ```
        進度百分比 = (實際完成量 / 總最低目標) × 100%
        ```
        
- **理想目標百分比**
    
    ```
    理想目標百分比 = (總理想目標 / 總最低目標) × 100%
    ```

| 狀態 | 條件 | 進度範圍 | 視覺回饋 |
