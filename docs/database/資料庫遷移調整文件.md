# 資料庫遷移調整文件：從本地資料庫改為外部資料庫（同主機部署）

## 目前架構分析

### 現有 docker-compose.yaml 配置
專案目前使用本地 Docker 容器運行以下資料庫服務：
- **PostgreSQL**: `postgres-dev` (開發) 和 `postgres-prod` (生產)
- **MongoDB**: `mongo_dev` 和 `mongo_prod`
- **Redis**: `redis_dev` 和 `redis_prod`

### 應用程式資料庫連接
- **配置文件**: `src/config/database.ts`
- **PostgreSQL 服務**: `src/services/database/postgres.service.ts`
- **Prisma 服務**: `src/services/database/prisma.service.ts`
- **環境變數**: `.env.dev_temp`, `.env.prod_temp`

### 遷移目標
將專案改為連接外部資料庫（在同一主機上），外部資料庫使用獨立的 docker-compose 配置管理：
- **PostgreSQL**: 改用外部容器 `postgres-dev`
- **ClickHouse**: 新增外部容器 `clickhouse-dev` 
- **Qdrant**: 新增外部容器 `qdrant-dev`
- **MongoDB**: 保留本地容器 `mongo_dev`
- **Redis**: 保留本地容器 `redis_dev`

### 6. 部署流程

#### 🚀 遷移步驟

1. **準備階段**：
   ```bash
   # 備份現有 PostgreSQL 資料
   docker-compose exec postgres-dev pg_dump -U daodao daodao > postgres_migration_backup.sql
   
   # 停止現有服務
   docker-compose down
   ```

2. **配置更新**：
   ```bash
   # 更新環境變數文件
   cp .env.dev_temp .env.dev
   # 填入正確的外部 PostgreSQL 連接資訊
   
   # 更新 docker-compose.yaml（移除 PostgreSQL 服務，保留 MongoDB 和 Redis）
   ```

3. **網路和外部資料庫設置**：
   ```bash
   # 創建外部網路
   docker network create dev-daodao-network
   
   # 在外部資料庫專案中啟動 PostgreSQL、ClickHouse、Qdrant
   cd /path/to/external-db-project
   docker-compose up -d postgres-dev clickhouse-dev qdrant-dev
   
   # 等待外部資料庫就緒
   docker-compose exec postgres-dev pg_isready -U ${DAO_POSTGRES_USER}
   
   # 驗證 ClickHouse 連接
   docker-compose exec clickhouse-dev clickhouse-client --query "SELECT 1"
   
   # 驗證 Qdrant 連接
   curl http://localhost:6333/health
   ```

4. **資料遷移**：
   ```bash
   # 恢復 PostgreSQL 資料到外部資料庫
   docker-compose exec -T postgres-dev psql -U ${DAO_POSTGRES_USER} -d ${DAO_POSTGRES_DB} < postgres_migration_backup.sql
   
   # 返回應用程式目錄
   cd /path/to/daodao-server
   
   # 同步 Prisma Schema
   docker-compose exec dev_app npx prisma db pull
   docker-compose exec dev_app npx prisma generate
   ```

5. **啟動應用程式服務**：
   ```bash
   # 啟動應用程式和保留的資料庫服務（MongoDB、Redis）
   docker-compose up -d
   
   # 驗證所有服務
   docker-compose ps
   
   # 測試資料庫連接
   docker-compose exec dev_app npm run typecheck
   
   # 測試 ClickHouse 連接（如果有相關代碼）
   docker-compose exec dev_app node -e "
     const client = require('@clickhouse/client').createClient({
       host: process.env.CLICKHOUSE_URL
     });
     client.ping().then(() => console.log('ClickHouse connected')).catch(console.error);
   "
   
   # 檢查應用程式日誌
   docker-compose logs dev_app
   ```
